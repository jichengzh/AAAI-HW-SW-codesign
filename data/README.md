# Demo data

`data/demo/` contains a tiny, deterministic smoke-test fixture. It is not a
benchmark, measurement corpus, or substitute for paper evidence. Every record
is marked `paper_evidence: false`, and its only intended use is an offline
smoke test of the public input contracts.

The four files describe two fictional graph/configuration combinations and
three candidate configurations. They deliberately use synthetic identifiers
and simple values; do not use them to report performance, select a model, or
derive any paper claim.
