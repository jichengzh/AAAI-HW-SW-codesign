# P3-13：历史测试候选逐项处置

状态：288 项历史测试代码候选已逐项审阅并形成仅本机保存的受限 decisions/ledger 检查点；未复制私有测试、未提交私有清单、未推送、未发布。

## 审阅方法

本批对每项候选单独执行 AST 测试属性检查、公开执行面导入反证、公开 API 测试覆盖检查、文件/网络/GPU 环境依赖检查和私有标识/绝对位置信号检查。全部候选都位于历史测试集合；公开运行时代码对这些私有测试文件的导入数为零，且没有同路径的公开内容替代物或第三方许可标记。

候选中带 GPU、网络、文件、绝对位置或私有信号的测试不会因其位置被误迁入。对每一项都以“当前支持的公开执行链不导入该私有测试”为依赖反证：如未来需要覆盖相同的公开 API，应以当前公开 fixture 和环境契约新建脱敏测试，而不能恢复旧测试文件。

| 处置 | 数量 | 固定 reason / evidence | 结论 |
| --- | ---: | --- | --- |
| `duplicate_or_superseded` | 23 | `public_contract_supersedes` / `public_test_coverage` | 当前公开测试已覆盖同一公开 API；历史测试不是支持链中的唯一验证来源。 |
| `excluded_nonessential` | 265 | `nonessential_to_supported_flow` / `public_contract_review` | 历史测试或混合测试辅助逻辑不被公开运行时导入；即使其带硬件、网络、文件或私有环境假设，也不属于已声明公开复现链。 |

该决定不声称旧测试没有研究价值，也不把公开 synthetic test 视为论文结果。它只定义发布边界：公开仓库只维护具有脱敏输入和明确环境/外部制品契约的测试。

## 本地账本检查点

受限台账的 288 条记录严格对应 P2 分类 `migrate_code`，计数为 23 条公开替代和 265 条非必要排除。生成的路径无关 ledger 仅保存 HMAC-SHA256 candidate ID、分类、受控 token 和后续阶段；泄露扫描确认没有路径、origin、正文、人员、机器、地址或 key。

P3 当前有 410/1,551 项可复核 decisions：前序 P3-9--P3-12 的 122 项与本批 288 项。它们都只是本机 audit checkpoint，不能替代最终全量 ledger 或 P3 关闭。
