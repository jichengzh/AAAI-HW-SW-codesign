# P2b：私有源盘点安全加固

状态：已完成本地修复、独立复审、只读重新盘点与当前全树验收；未推送、未发布。

## 触发原因

对 P2a 工具的独立复审发现两个不能继续依赖旧候选清单的缺口：嵌套的数据目录段可能被分类为迁移候选，且候选读取的稳定性不足以完全防止检查与读取之间的链接或元数据变化。没有确认已发生内容泄露；本批次的目的只是让后续 P3 选择在失败时保守地停止，而不是扩大候选面。

## 修复后的边界

`tools/release/inventory_private_source.py` 升级为 `private-source-inventory/1.1.0`。它在任意路径层级将精确的数据目录段分类为 `external_input`，而项目中名为 `tests` 的源码目录不受该规则影响。候选读取继续逐段 no-follow 打开，并新增以下失败关闭条件：不是普通文件、链接数不为一、读取前后设备/inode/mode/link-count/size/mtime/ctime 任一变化，都会转为不透明复核条目而不是读取或输出候选路径。

新增回归覆盖嵌套数据目录、正常测试源码、硬链接以及 mtime 恢复但 ctime 改变的读取竞争。定向测试为 `5 passed`；Ruff、`compileall` 和 diff 空白检查通过。独立复审确认不存在 high/medium blocker。与同期 P3-1 加固组合后的最终全树验收为 `405 passed`、总覆盖率 81.95%；匿名 ZIP 已独立 build/verify（113 成员，SHA-256 `96a3bc9b6980e2f25bb9ab102cc950ba2ff57f9fb7c2f35142d2367818b319f6`）。

## 后续边界

P2b 只保证清单生成的安全边界，不构成任何候选的公开许可。每个 P3 批次仍须重新检查语义、身份/路径回显、第三方许可、外部输入和生成物边界；P4 继续负责合法的数据、模型和其他外部输入获取。
