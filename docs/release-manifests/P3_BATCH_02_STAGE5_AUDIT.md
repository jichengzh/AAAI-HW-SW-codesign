# P3-2：Stage5 候选审阅（未批准迁移）

状态：已完成只读审阅；本批次不迁移代码、不提交数据、不执行硬件任务。

## 审阅范围

本批次重新审阅 Stage5 的四个私有 `migrate_code` 候选：源注册表、两个测量计划模块，以及 `closure_v3` 聚合审计器。它们均未自动获得迁移许可。

源注册表和测量计划模块会处理 checkpoint、制品目录、校准目录、远端结果根或显式证据文件；即使它们本身通过文本禁用模式扫描，仍属于 P4 外部输入契约和 P5/P6 执行环境的范围，不能在 P3 直接公开。

`closure_v3` 不主动读取文件，但其输出会条件性保留调用者输入中的结果和证据位置。这个行为可能将私有路径重新写入公开 JSON 报告，因此同样不批准直接迁入。

## 所需改造与后续决定

将来若迁入 `closure_v3`，必须先完成以下改造并以测试锁定：

1. 报告只保留外部输入的逻辑制品 ID、SHA-256 和可用性状态，不保留路径或 URI；
2. 证据 SHA-256 必须符合固定长度十六进制格式，缺失或漂移时失败关闭；
3. 实际证据文件的获取、位置解析、许可和哈希校验属于 P4，不由 closure 模块隐式执行；
4. 以脱敏的合成行完成 unit/integration tests，且不将真实测量、AP、模型或结果文件纳入仓库。

该决定不影响 P3-1：P3-1 的 Stage6 合约层继续只声明结构化外部证据种类，不读取或回显外部路径。

## 下一批原则

P3-3 仅从 P2 清单中选择同时满足以下条件的模块：纯 Python、无文件/网络/硬件副作用、不回显调用者提供的路径或私有 provenance、具有可迁移的合成测试，并且能明确说明其对公开复现流程的作用。
