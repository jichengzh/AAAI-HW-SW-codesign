## 已核实的诊断

P4 五个实际终局均为 `Failed - Agent timed out`，CARLA 游戏时间 278.05 s；无碰撞或 blocked 记录，不能称为模型性能比较完成。

结果最新缓存没有解决推理入口的 FIFO 积压。`trigger_capacity=4096`，推理与发送串行，28 MiB 级未压缩结果沿既有 ROS/SSH/ZeroTier 链路回传。到当前帧 5560 时，五组最后可用 source frame 仅为 392、474、808、942、1988。五组平均信息年龄约 87.09–130.35 s，远大于此前 100–800 ms 注入实验尺度。

平均车速约 0.50–1.14 m/s；同起点非 HIL 历史样例可达到 RC=100，平均约 2.85 m/s。积压与超时关联明确，但仍需修复后的实测才能确认因果及剩余因素，不能只调大 timeout。

另一个独立问题：现有输入只覆盖 Town05 的 `_1:r2` 一项（2225 帧）。缓存存储两节点预处理张量，但无采集时位姿/变换；精确 frame/SHA 对应只能证明字节身份，不能证明各模型分叉后的真实闭环观测仍一致。此项尚未解决，不因队列测试通过而标成 P5 ready。
