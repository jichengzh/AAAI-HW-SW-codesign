# P4 完整外部资源登记设计

## 目标与范围

P4 将 P3 已转交的 506 条 `external_contract_p4` 候选，在本地按真实外部资源去重，生成完整、可公开的外部输入注册表。登记对象仅限完整复现需要的外部数据集、模型、checkpoint、ONNX、engine、测量/证据包和可再生成大文件；论文、方法、分析和其他纯文档候选不生成资产记录。

本设计不下载、迁入、运行或发布任何外部资产，也不执行 GPU、训练、评测或硬件任务。SHA-256 保持可选，只有上游已公开摘要或项目确实需要固定资产版本时才记录。

## 输入与信任边界

受限 P3 逐项复核 JSON 仅在本机以显式命令行参数传入。它保留候选的私有定位、职责、输入/输出、来源/许可证和审查字段，不能进入 Git、公开 registry、覆盖摘要、测试 fixture、命令输出或审计正文。

本地维护一份不入库的 resolution JSON。它为每个 P4 候选给出以下之一：

- `document`：该候选没有独立外部资源职责，不生成公开记录；
- `asset`：该候选关联一个安全的公开 `resource_id`。

多个 `asset` 候选可以关联同一个 `resource_id`，从而按真实资源去重。resolution 同时持有该资源的公开元数据：资产类别、公开可表达的来源、许可/再分发结论、版本、用途、相对路径、消费者和可用性。它可以在本机包含候选定位，但编译器绝不把该定位写入公开输出。

## 本地解析与编译

新增两个仅离线运行的工具，所有输入、输出路径均由调用者显式提供：

1. 候选提取器从受限 P3 复核文件筛出 `external_contract_p4` 记录，基于 `actual_role`、`inputs`、`outputs`、`evidence_artifact` 和来源/许可证审查字段生成本地资源候选草案。它按可公开的资源类别打标签，并把无法自动归并的项保留在本地待裁决队列；不向终端打印私有字段。
2. 注册表编译器读取受限 P3 复核、已裁决的本地 resolution 和现有 registry 格式。它要求 506 条 P4 候选逐条有唯一决策，要求每个 `asset` 决策引用一个资源，要求每个资源至少被一个候选使用。通过后才写入公开 registry 和公开覆盖摘要。

公开 registry 延续 `aaai27_external_input_registry_v1`。公开覆盖摘要使用独立格式，只报告 P3 P4 候选总数、文档候选数、资源候选数、去重后资源数、按资产类别的数量和按可用性的数量；不含候选 ID、私有路径、原文、来源私密细节或映射表。

已有 `validate_external_inputs.py` 继续作为消费端：它只读取已编译的公开 registry 和调用者显式提供的资产目录，不读取 P3 资料，也不下载或执行资产。

## 错误处理与收口规则

解析器无法读取受限文件、P3 记录格式不符、候选无法裁决、resolution 重复/缺失、资源元数据不完整或公开输出含映射字段时，命令以非零状态退出且不写部分公开产物。错误信息仅指出安全的结构性原因和数量，不回显私有值。

P4 仅在以下条件同时满足时改为“已完成（本地）”：

- 所有 506 条 P3 P4 候选均有 `document` 或 `asset` 决策；
- 每个 `asset` 决策均被去重并编译为符合现有契约的公开资源记录；
- 覆盖摘要与 registry 的类别、数量和可用性一致；
- registry 与离线验证器的单元/集成测试通过；
- 当前 CI 的 Python 3.10 和 3.11 质量门均为绿色。

当前 CI 已知的匿名归档 allowlist 在 Python 3.10/3.11 对 `directory/**` 的展开与 Python 3.13 不同。收口前将把该清单改为显式文件递归模式，并以现有归档测试验证两个受支持解释器的行为；这不扩大 P4 的资源范围。

## 测试策略

测试使用合成 P3 复核记录和临时 resolution 文件，覆盖：P4 筛选、文档排除、多个候选去重到单一资源、未裁决/重复决策失败、字段不完整失败、公开输出不含合成私有路径或候选 ID，以及覆盖摘要与 registry 一致。已有离线验证器测试继续覆盖 unavailable、缺失与可选校验和。

归档兼容修复先以现有匿名归档 fixture 产生失败，再将递归文件清单改为跨 Python 3.10--3.13 一致的形式。最终运行质量门同等命令和 public-smoke，确认 CI 恢复绿色。

## 非目标

- 不向公开仓库写入受限 P3 JSON、resolution、候选 ID、私有路径、原文或 HMAC key；
- 不把 P4 文档候选伪装为外部资产；
- 不推断不存在的来源、许可证、版本或 SHA-256；事实缺失的资源如实标为 `unavailable`；
- 不执行 P5 环境配置、P6 实验/硬件执行、P7 安全合规收口或 P8 发布动作。
